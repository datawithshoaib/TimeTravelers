# TimeTravelers Source & Ingestion Policy

## 1. Source Quality Hierarchy
1. **Primary Sources (Tier 1)**: Authentic original writings, speeches, letters, and scientific memoirs held in recognized national libraries (e.g., British Library, Oxford Bodleian, Library of Congress, Vatican Archives).
2. **Verified Scholarly Editions (Tier 2)**: Standard critical recensions (e.g., Oxford Classical Texts, Edizione Nazionale delle Opere di Galileo Galilei).
3. **Secondary Historical Context (Tier 3)**: Peer-reviewed historical biographies and commentary; must be explicitly tagged as secondary context.
4. **General Reference (Tier 4)**: Cautiously utilized only for chronological anchors.

## 2. Rights and Copyright Assessment
- Public domain status is verified per jurisdiction (life of author + 70/100 years).
- Specific translations and digital scans carry independent copyright status and must be verified.
- Open-access scholarly editions are ingested with explicit attribution metadata and canonical links.

## 3. Transcription and OCR Integrity
- Low-confidence OCR passages are marked with uncertainty flags.
- Exact quotation formatting is prohibited on damaged or disputed text.
- Editorial corrections are versioned under `collection_version`.
